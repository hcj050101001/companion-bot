# 安全网关

## 请求路径

OneBot webhook 首先执行 body 大小限制和签名校验，然后解析事件。解析成功的私聊不按白名单过滤，进入 `EventProcessor.handle` 后，安全网关在 brain 之前运行：规则关键词命中或配置的 LLM provider 判定为危机，任一命中均触发危机流程。模型未知或调用失败按未命中处理；规则命中仍独立有效。

危机流程只使用配置热线生成固定话术，并通过告警器报告元数据；不会把聊天原文交给告警器。非危机消息通过限流后才进入 brain 和短期记忆。brain 的模型失败返回温和兜底回复。

## 输出覆盖

对外输出目前只有 `OneBotClient.send_private_msg`。它只在完成事件解析及相应安全处理后由处理器调用；危机和普通回复都由同一个输出调用发送。群消息、reaction、QQ 空间和好友管理接口当前为关闭/未执行的工具接口。新增任何消息、HTTP、邮件、文件或其他外部输出路径时，必须在其调用前经过 `SafetyGateway`；不能从 brain、后台任务或异常处理器直接绕过网关发出用户可见内容。

安全网关检查的是输入风险并决定固定危机回复；模型生成的普通回答仍须遵守人格和隐私约束。日志和告警只存必要元数据，不存聊天原文。
